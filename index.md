# Personal Drive Backup

Personal Drive Backup is a private, single-user tool. It is the open-source program
[rclone](https://rclone.org/), run by the owner of this page on his own computer, to keep
a backup copy of his own project files in his own Google Drive.

- Users: one — the owner of this page. The app is not offered to anyone else.
- Google access: only the files and folders that this app itself created in the owner's
  Google Drive (scope `drive.file`).
- No server, no accounts, no analytics, no advertising.
